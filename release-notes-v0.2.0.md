## Primer Empleado IA beta v0.2.0

Esta es la primera versión pública de prueba para los primeros 10 negocios.

Incluye:

- conversación guiada con Lía por texto o voz;
- definición de una tarea repetitiva en lenguaje cotidiano;
- creación de un empleado con acciones permitidas, prohibidas y aprobaciones;
- instalador de Windows por usuario, sin permisos de administrador;
- conexión segura entre la web pública y el Companion local;
- entrega del empleado a Hermes Desktop;
- inicio automático del Companion y accesos desde el menú Inicio.

Requisitos:

- Windows 10 u 11;
- Hermes Desktop instalado y funcionando;
- Chrome o Edge para la experiencia de voz.

Importante: esta beta aún no tiene firma Authenticode, por lo que Windows puede advertir que el editor es desconocido. El archivo JSON adjunto contiene los hashes verificables del instalador y del contenido interno.
