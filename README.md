# Primer Empleado IA — Descargas públicas

Este repositorio contiene únicamente los instaladores públicos y la evidencia automática de la beta de **Primer Empleado IA**.

## Beta privada para los primeros 10 negocios

1. Abre [Primer Empleado IA](https://primer-empleado-ia.vercel.app/crear).
2. Conversa con Lía por texto o voz y explícale la tarea repetitiva que quieres delegar.
3. Revisa el trabajo, los permisos y los límites de tu empleado.
4. Descarga el instalador de Windows cuando Lía te lo indique.
5. Abre el instalador y regresa a la web con el acceso **Crear mi empleado IA**.

## Requisitos de esta beta

- Windows 10 u 11.
- Hermes Desktop instalado y funcionando.
- Chrome o Edge para usar voz.
- Acompañamiento inicial de Agencia IA para los primeros 10 negocios.

## Aviso de seguridad

La beta `v0.2.0` todavía no tiene firma Authenticode. Windows puede mostrar una advertencia de editor desconocido. El hash SHA-256 se publica junto con cada instalador y una máquina Windows limpia verifica automáticamente el paquete después de cada publicación.

Esta beta nunca mueve dinero ni verifica pagos por su cuenta. El dueño del negocio revisa y aprueba las acciones sensibles.
